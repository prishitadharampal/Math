Let $R$ be a ring. A \emph{left $R$-module} is an abelian group $(M,+,0_M)$ together with a scalar multiplication $R\times M\to M$, written $(r,m)\mapsto rm$, satisfying the following axioms:
\begin{enumerate}[label=(\roman*)]
	\item (Identity) $1_Rm=m$ for all $m\in M$,
	\item (Associativity) $(rs)m=r(sm)$ for all $r,s\in R$ and all $m\in M$,
	\item (Left Distributivity) $r(m+n)=rm+rn$ for all $r\in R$ and all $m,n\in M$, and
	\item (Right Distributivity) $(r+s)m=rm+sm$ for all $r,s\in R$ and all $m\in M$.
\end{enumerate}
We write $rm$ for the scalar multiplication of $r\in R$ and $m\in M$, and we write $0$ for $0_R$ or $0_M$ when the intended identity is clear from context. Unlike a ring, a module need not have a multiplication of its own elements. The associativity axiom describes how multiplication in $R$ interacts with its action on $M$: acting by $s$ and then by $r$ is the same as acting by $rs$.

A \emph{right $R$-module} has its scalars acting on the right, with associativity given by $m(rs)=(mr)s$. Unless we say otherwise, \emph{module} will always mean left module. In a commutative ring the two notions agree by setting $mr=rm$, but in an arbitrary ring it is important to keep track of the side on which scalars act. As in the previous worksheet all rings have a multiplicative identity, but need not be commutative, and the letter $\K$ will denote a field.

The goal of this worksheet is to introduce modules and study their submodules, homomorphisms, and quotients. Modules generalize vector spaces by allowing scalars to come from a ring. You already know several examples, including vector spaces and abelian groups. The definitions let us study these examples together, while retaining differences such as whether a module has a basis.

Let $M$ be an $R$-module. A \emph{submodule} $N\subset M$ is an additive subgroup which is closed under the $R$-action, so that the action of $R$ on $M$ restrict to an action of $R$ on $N$. (There might be some sort of diagram you might draw here.) Equivalently, $N$ is nonempty and $rn+sn'\in N$ whenever $r,s\in R$ and $n,n'\in N$. This is the same closure condition used to recognize subspaces, with the scalars now taken from $R$.

Let $M$ and $N$ be $R$-modules, a \emph{module homomorphism}, or \emph{$R$-linear map}, is a function $\phi:M\to N$ satisfying the following conditions for all $m,m'\in M$ and all $r\in R$:
\begin{enumerate}[label=(\roman*)]
	\item $\phi(m+m')=\phi(m)+\phi(m')$.
	\item $\phi(rm)=r\phi(m)$.
\end{enumerate}
Notice the first condition says that $\phi$ is a homomorphism of the underlying abelian groups. In particular it preserves $0$ and additive inverses. The second says that $\phi$ respects the scalar action. We write $\Hom_R(M,N)$ for the set of such maps. We call a homomorphism from a module to itself a \emph{endomorphism} and so $\End_{R}(M) \coloneqq \Hom_{R}(M,M)$.

A module homomorphism is an \emph{isomorphism} if it has an inverse which is again a module homomorphism. As with groups and rings, this turns out to be equivalent to the set theoretic condition of being a bijection. We write $M\cong N$ when an isomorphism exists. An \emph{automorphism} of $M$ is an isomorphism $\phi:M \to M$. We denote the set of $R$-linear automorphisms by $\Aut_{R}(M) \subset \End_{R}(M)$.

As with ring homomorphisms, a module homomorphism $\phi:M\to N$ comes with a \emph{kernel} and an \emph{image}:
\[
\ker(\phi) \coloneqq \left\{ m \in M \;\; \big| \;\; \phi(m) = 0_N \right\}\subset M \qquad \text{and} \qquad \img(\phi) \coloneqq \left\{\phi(m) \;\; \big| \;\; m \in M\right\} \subset N.
\]
A homomorphism is surjective exactly when its image is the whole target, while its kernel measures its failure to be injective. Whether an additive subgroup is a submodule depends on the ring action. For example, a subspace of $\K^2$ need not be preserved by every matrix in $\Mat_2(\K)$. We will see this distinction in the following exercise.

Modules over the polynomial ring $\K[x]$ give a useful dictionary between module theory and linear algebra. Let $V$ be a $\K$-vector space and let $T:V\to V$ be a linear operator. Substituting $T$ for $x$ defines an action of $\K[x]$ on $V$ by the rule
\[
\left(a_0+a_1x+\cdots+a_dx^d\right)v
\coloneqq a_0v+a_1T(v)+\cdots+a_dT^d(v),\qquad T^0\coloneqq\Id_V.
\]
We write $V_T$ for the resulting module. Constant polynomials act by the original scalar multiplication on $V$, and the variable $x$ acts by $T$. Conversely, a $\K[x]$-module becomes a vector space once we restrict the scalars to the constant polynomials, and multiplication by $x$ is then a linear operator on that vector space. A $\K[x]$-module is therefore the same thing as a vector space together with a choice of linear operator. The variable $x$ is still a formal symbol; it is the module structure which specifies how it acts.

This dictionary also translates submodules and homomorphisms. Let $W$ be a $\K$-vector space with a linear operator $S:W\to W$. A $\K$-linear map $\phi:V\to W$ is a module homomorphism $V_T\to W_S$ if and only if $\phi\circ T=S\circ\phi$, in which case we call $\phi$ an \emph{intertwining map}. Similarly, a subspace $U\subset V$ is a submodule of $V_T$ if and only if $T(U)\subset U$, in which case we call $U$ a \emph{$T$-invariant subspace}. These translations let us study a linear operator by studying its module, a point of view we will return to when we discuss canonical forms. We check the dictionary in the following exercise.

Let $N\subset M$ be a submodule. Since $N$ is an additive subgroup of the abelian group $M$, we may form the quotient group $M/N$, whose elements are the cosets $m+N$, with $m+N=m'+N$ if and only if $m-m'\in N$. To obtain a \emph{quotient module}, we define a scalar multiplication by
\[
r(m+N)\coloneqq rm+N.
\]
The fact that $N$ is closed under the action of $R$ guarantees that this formula does not depend on the chosen representative. Together with the addition $(m+N)+(m'+N)=(m+m')+N$, it makes $M/N$ an $R$-module. The \emph{quotient map}
\[
\begin{tikzcd}[row sep=.3em,column sep=4em]
	M \arrow[r,"\pi"] & M/N & & m \arrow[r,mapsto] & m+N
\end{tikzcd}
\]
is a surjective module homomorphism with kernel $N$. Consequently, every submodule occurs as the kernel of a module homomorphism, just as every two-sided ideal occurs as the kernel of a ring homomorphism.

One way to think of $M/N$ is as the module obtained by imposing the equations $n=0$ for all $n\in N$. More precisely, a module homomorphism $\phi:M\to P$ which vanishes on $N$ determines a unique module homomorphism $\overline{\phi}:M/N\to P$ such that $\overline{\phi}\circ \pi=\phi$:
\[
\begin{tikzcd}[column sep=4em,row sep=4em]
	M \arrow[r,"\phi"] \arrow[d,two heads,"\pi"'] & P \\
	M/N \arrow[ur,dashed,"\overline{\phi}"'] &
\end{tikzcd}
\]
This is the \emph{universal property of quotient modules}. As with quotient rings, it describes homomorphisms out of $M/N$ in terms of homomorphisms out of $M$ which send $N$ to zero. We check the construction and this property in the following exercise.

The construction of quotient modules also explains the relationship between the kernel and the image of a homomorphism $\phi:M\to P$. Two elements of $M$ have the same image exactly when their difference lies in $\ker(\phi)$. Passing to $M/\ker(\phi)$ therefore identifies exactly the elements that $\phi$ identifies. The induced map is injective and has image $\img(\phi)$.

\begin{theorem}[First Isomorphism Theorem for Modules]
	Let $\phi:M\to P$ be a homomorphism of $R$-modules. Then the map
	\[
	\overline{\phi}:M/\ker(\phi)\longrightarrow\img(\phi),
	\qquad m+\ker(\phi)\longmapsto \phi(m),
	\]
	is an isomorphism of $R$-modules. In particular, there is a commutative diagram
	\[
	\begin{tikzcd}[row sep=4em,column sep=4em]
		M \arrow[r,"\phi"] \arrow[d,two heads,"\pi"'] & P \\
		M/\ker(\phi) \arrow[r,"\overline{\phi}","\sim"'] & \img(\phi) \arrow[u,hook]
	\end{tikzcd}
	\]
\end{theorem}

Every module homomorphism can therefore be expressed as a quotient map followed by an isomorphism and an inclusion. If $\phi$ is surjective, the theorem gives $M/\ker(\phi)\cong P$. As with rings, we can recognize a quotient module by constructing a surjective homomorphism onto a module we already understand and computing its kernel. The familiar versions for abelian groups and vector spaces are special cases. We prove the theorem and apply it in the following exercise.

The first isomorphism theorem also lets us compare quotients which are constructed in different ways. Let $A,B\subset M$ be submodules. Their \emph{sum} is
\[
A+B\coloneqq\left\{a+b \;\; \big| \;\; a\in A,\ b\in B\right\},
\]
which is the smallest submodule of $M$ containing both $A$ and $B$. Passing to $(A+B)/B$ has the effect of setting the elements of $B$ equal to zero, so every class can be represented by an element of $A$ alone. The part of $A$ which becomes zero in the process is exactly $A\cap B$. The second isomorphism theorem is the precise form of this observation, and its proof is a single application of the first.

\begin{theorem}[Second Isomorphism Theorem for Modules]
	If $A$ and $B$ are submodules of an $R$-module $M$, then
	\[
	A/(A\cap B)\ \xrightarrow{\ \sim\ }\ (A+B)/B,
	\qquad a+(A\cap B)\longmapsto a+B
	\]
	is an isomorphism of $R$-modules.
\end{theorem}

Suppose $N\subset L\subset M$ are submodules. We may form $M/L$ directly, or we may first form $M/N$ and then take the quotient by $L/N$. The third isomorphism theorem says that these two constructions give isomorphic modules. The correspondence theorem describes all submodules of $M/N$ in terms of the submodules of $M$ which contain $N$.

\begin{theorem}[Third Isomorphism and Correspondence Theorems]
	Let $N\subset M$ be a submodule and let $\pi:M\to M/N$ be the quotient map. The assignments $L\mapsto L/N=\pi(L)$ and $U\mapsto \pi^{-1}(U)$ give mutually inverse, inclusion-preserving bijections
	\[
	\left\{L\subset M \;\; \big| \;\; L\text{ a submodule containing }N\right\}
	\longleftrightarrow
	\left\{U\subset M/N \;\; \big| \;\; U\text{ a submodule}\right\}.
	\]
	Moreover, for $N\subset L\subset M$ there is an isomorphism of $R$-modules
	\[
	(M/N)/(L/N)\ \xrightarrow{\ \sim\ }\ M/L,\qquad
	(m+N)+(L/N)\longmapsto m+L.
	\]
\end{theorem}

Since the quotient map sends every element of $N$ to zero, the preimage of any submodule of $M/N$ contains $N$. Conversely, a submodule $L\subset M$ containing $N$ determines the submodule $L/N\subset M/N$. The correspondence theorem says that these two constructions undo one another and preserve inclusion. We prove both statements in the following exercise.

Let $M$ and $P$ be $R$-modules. The set $\Hom_R(M,P)$ is itself an abelian group under pointwise addition:
\[
(f+g)(m)=f(m)+g(m),\qquad (-f)(m)=-f(m),
\]
with the zero homomorphism as its identity element. Thus the collection of homomorphisms between two modules is again an algebraic object of the same general kind. Over a commutative ring, pointwise scalar multiplication also makes $\Hom_R(M,P)$ an $R$-module. Since our rings need not be commutative, we use only its abelian group structure here.

Maps out of cyclic modules give the first computations of this kind. Such a map is determined by the image of a generator, but that image is not arbitrary: it must satisfy whatever relations the generator satisfies. For a positive integer $m$, a homomorphism from $\Z/m\Z$ to an abelian group $P$ is therefore the same thing as an element $y\in P$ with $my=0$. When $P=\Z/n\Z$ this description leads to
\[
\Hom_{\Z}(\Z/m\Z,\Z/n\Z)\cong\Z/\gcd(m,n)\Z.
\]
In the following exercise we construct this isomorphism by finding the possible images of $\overline1$, and then use the same description to compute kernels and images in some examples.

We finish by describing module structures in terms of ring homomorphisms. Recall from Worksheet 1.1 that for an abelian group $M$, the endomorphism ring $\End_{\Z}(M)=\Hom_{\Z}(M,M)$ has pointwise addition and multiplication given by composition, with $fg=f\circ g$. Its multiplicative identity is $\Id_M$.

If $M$ is an $R$-module, then multiplication by a scalar $r$ is an additive map $\rho(r):M\to M$, where $\rho(r)(m)=rm$. The module axioms say exactly that the resulting function
\[
\rho:R\longrightarrow\End_{\Z}(M)
\]
is a ring homomorphism. For instance, the associativity axiom $(rs)m=r(sm)$ becomes the identity $\rho(rs)=\rho(r)\circ\rho(s)$, and the identity axiom $1_Rm=m$ becomes $\rho(1_R)=\Id_M$, which is condition (iii) in the definition of a ring homomorphism. Conversely, any such ring homomorphism defines an $R$-module structure on the abelian group $M$. Thus giving an $R$-module structure on $M$ is the same thing as giving a ring homomorphism $R\to\End_{\Z}(M)$.

Once an $R$-action has been fixed we may form the ring $\End_R(M)$ of those endomorphisms which respect it. This is a subring of $\End_{\Z}(M)$, with the same addition, composition, and identity element, and it acts on $M$ by \emph{evaluation}, $f\cdot m=f(m)$. The condition $f(rm)=rf(m)$ says precisely that this action commutes with the original one. Note that over a noncommutative ring the scalar operators $\rho(r)$ need not themselves be $R$-linear, which is why the target of $\rho$ is $\End_{\Z}(M)$ and not $\End_R(M)$. The column module over $\Mat_2(\K)$ makes this distinction concrete, as we see in the following exercise.
